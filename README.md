# Modelo Predictivo de Uso de Tecnología en Estudiantes

Proyecto de Ingeniería de Sistemas enfocado en el análisis del uso excesivo de la tecnología en estudiantes universitarios del departamento de Boyacá.

## Objetivo
Desarrollar un modelo predictivo que identifique riesgos asociados al uso excesivo de dispositivos tecnológicos.

## Tecnologías usadas
- Python
- Pandas
- Scikit-learn
- Google Colab

## Modelo
Se utilizó Random Forest para clasificación binaria.

## Resultados
- Accuracy: 93%
- Variables más importantes:
  - Redes sociales
  - Tiempo de pantalla
  - Uso en fines de semana

## Dataset
Smartphone Usage and Addiction Analysis (7500 registros)
